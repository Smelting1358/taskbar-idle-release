# Taskbar Idle

윈도우 작업표시줄 위에 붙어서 돌아가는 방치형 RPG입니다. 일을 하는 동안 화면 아래쪽에서 주인공과 동료가 알아서 싸우고, 장비를 얻고, 강해집니다.

## 웹에서 바로 플레이

👉 **https://smelting1358.github.io/taskbar-idle-release/**

- 설치 없이 브라우저에서 바로 실행됩니다(처음 로딩 약 40MB). PC 브라우저(크롬·엣지 등)를 권장합니다.
- 진행은 그 브라우저에 저장됩니다(10초마다). 다른 브라우저나 PC와는 이어지지 않습니다.
- 웹에서는 작업표시줄에 붙거나 창을 옮기는 기능이 없고, 메뉴·스테이지 지도·전투 화면이 한 화면에 보입니다.
- 탭을 닫거나 다른 탭에 오래 두면 멈추고, 다시 열면 그동안의 진행을 오프라인 보상으로 받습니다.
- 아이폰·안드로이드 브라우저에서도 열리지만 화면이 작고, 아이템 정보(마우스 올리기)·우클릭 판매는 터치로 안 됩니다.

## 내려받기

[**Releases**](../../releases/latest)에서 `TaskbarIdle_win64.zip`을 받아 압축을 풀고 `TaskbarIdle.exe`를 실행하세요. 설치는 필요 없습니다.

- Windows 10 / 11 (64비트)
- 서명되지 않은 실행파일이라 처음 실행할 때 **"Windows의 PC 보호"** 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
- 진행은 `%APPDATA%\Godotpp_userdata\Taskbar Idle Prototype\save.json`에 30초마다 자동 저장됩니다. 꺼 둔 동안의 진행은 다음 실행 때 오프라인 보상으로 받습니다.

## 조작

- **메뉴** 버튼(전투 띠 오른쪽 아래): 가방 · 캐릭터 · 합성 · 부적 · 상점 · 도깨비방망이, 오른쪽에 스테이지 지도
- 전투 띠를 **끌면** 화면 어디로든 옮길 수 있습니다. 설정(메뉴 오른쪽 위 깃발) → **작업표시줄에 붙이기**로 되돌립니다.
- 주인공이나 동료를 클릭하면 캐릭터 탭이 열립니다.
- 가방: 클릭 장착 · 우클릭 판매 · 마우스를 올리면 아이템 정보
